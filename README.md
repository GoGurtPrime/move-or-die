# MOVE OR DIE

A fast, browser-based raymarched arena shooter. Time moves when you do. Clear escalating waves, dodge purple orb bursts, and survive the occasional emergency blackout.

## Play

Open `index.html` in a modern browser, or use the published GitHub Pages URL.

Desktop controls:

- `WASD`: move
- `Mouse`: look
- `Click` or hold: fire
- `Shift`: sprint
- `Space`: jump

Mobile controls:

- Drag the left stick to move; tap it to jump.
- Drag the right stick to look; tap it to fire.

## Publish On GitHub Pages

1. Create a new GitHub repository and push this project to its default branch (`main`).
2. In the repository, open **Settings** > **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. Wait for GitHub Pages to deploy. The game will be available at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

The repository root already contains `index.html`, so no build step is required. Keep the `music` folder alongside `index.html` because the game loads its soundtrack from there.
